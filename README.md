# Novely

Lecteur Android personnel de light novels et webnovels, en français.

[Télécharger la dernière APK Android](https://github.com/UlTRA-Z-k4/Novely/releases/latest)

Dans les fichiers de la version, choisir **Novely-X.Y.Z.apk**, puis l’ouvrir sur Android. Pour une mise à jour, installer par-dessus la version existante **sans désinstaller** afin de garder la progression.

À partir de Novely 0.5, les livres sont séparés de l’APK. La bibliothèque est déjà remplie : un tome se télécharge automatiquement à sa première ouverture, puis reste lisible hors connexion. Il n’y a aucun import manuel. Les mises à jour se vérifient dans **Profil → Rechercher des mises à jour** ; Android demande ensuite de confirmer l’installation de la nouvelle APK.

Le catalogue français se trouve dans catalogue-fr.json. Les EPUB sont dans la publication [Bibliothèque française](https://github.com/UlTRA-Z-k4/Novely/releases/tag/books), conservée séparément des versions de l’application.

5 œuvres, 101 EPUB : Classroom of the Elite (25 tomes : année 1 complète, année 2 jusqu’au 9.5), Shadow Slave (traduction NovelFrance), Re:Zero (28), Mushoku Tensei (30), Sword Art Online (17 tomes fournis ; 10–18 et 25 absents des sources). Les traductions automatiques restent partiellement relues ; les pages reproduites en images conservent leur langue d’origine. Auteurs et crédits restent dans les EPUB.

Android 7 minimum. Les archives « Source code » de GitHub ne contiennent pas le projet complet et ne sont pas à installer.

Novely 0.10.0 : fiche d’œuvre et chapitres repensés, tomes dépliables, accès par tranches, recherche et suivi lu/non lu simplifié avec annulation. Boutons Précédent/Suivant en fin de chapitre ; Suivant coche celui quitté. Barre de progression par chapitre. Shadow Slave organisé en 13 volumes logiques dans le même EPUB. Les livres et leurs identifiants restent identiques à 0.9.1.
